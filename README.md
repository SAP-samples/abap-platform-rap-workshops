# Workshops about Development with ABAP Cloud 

## Description

This page contains a collection of materials for hands-on sessions at customer, partner, and community events focused on the ABAP Cloud development model (ABAP Cloud for short). 

ABAP Cloud is the development model for building lifecycle-stable and cloud-ready apps, services, and extensions that follow clean core principles by default. ABAP Cloud is available on SAP BAIP ABAP environment, SAP S/4HANA Cloud Public Edition (3-system landscape required), and on SAP S/4HANA Cloud Private Edition and SAP S/4HANA as of Release 2022. The ABAP RESTful application programming model (RAP) is at the heart of ABAP Cloud for transactional scenarios. Agentic AI and ABAP AI capabilities in SAP Joule for Developers help developers write and analyze ABAP code faster in the ABAP development tools.

Learn more:  [ABAP Cloud Development Model](https://help.sap.com/docs/abap-cloud) | [ABAP RESTful Application Programming Model (RAP)](https://pages.community.sap.com/topics/abap/rap)
